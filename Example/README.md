# Fernando Video AI

Aplicación privada de edición de vídeo para iPhone basada en VideoEditorKit.

## Objetivo V1
- Importar vídeo desde Fotos
- Recortar y editar
- Formato vertical para redes sociales
- Exportar y compartir
- Guardar proyectos

## Siguiente fase
- Subtítulos automáticos
- Eliminación de silencios
- Edición asistida por IA


## Nuevo foco: Foto a vídeo con IA
- Elegir una foto desde el iPhone
- Describir el movimiento deseado
- Generar un clip corto vertical 9:16
- Previsualizar el resultado
- Abrir el vídeo generado en el editor existente
- Exportar para Instagram

La integración se diseñará con un proveedor de generación de vídeo intercambiable para no acoplar la app a un único servicio.
